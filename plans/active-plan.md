# 当前执行计划

## 目标

把 M15 长桥模拟账户行情固定为官方 `longbridge==4.5.0` SDK 的单一长期 WebSocket 连接。证明147只生产池的盘中五分钟K线完整、及时且可审计。2026-09-08用户明确授权当晚模拟订单全流程联调：不等待前一完整只读交易日，但每根实时边界、账户、部署、合同和原有风控必须通过。策略、仓位、止损、目标和策略名单冻结。

## 2026-09-08 当日订单联调

- 日期限定配置 `paper_validation_market_date=2026-09-08` 与明确 `paper_validation_approved=true`，仅纽约当日有效，进程仍须显式 `--dispatch`。隐藏启动入口只有有效当日授权才携带该参数。
- 该授权只改变“先等一个完整只读日”的推进次序，不修改任何行情新鲜度、逐根完整性、账户和风险限制，不制造测试信号或订单、不自动清仓。
- 完整交易日门禁保持启用和独立统计；联调资格不得伪装成78/78边界通过。翌日若仍无整场通过证据，停止新开仓，现有退出通道保留。
- SDK内部重连不可观测的限制仍属已知缺口；按实时参考活动、边界、积压和账户状态停机，不声称已经证明零内部重连。
- 本轮同时修复跨系统重启身份判断、历史订单读取和超时请求待确认；修复代码必须独立分支、测试、远端检查点、干净部署。
- 北京时间21:35单次心跳检查首个完整边界、当前授权、真实订单号/成交和退出；没有合格信号允许零订单，不得补旧单。

## 唯一现行方案

1. 行情仅由一个官方 SDK `AsyncQuoteContext` 连接提供，同一连接订阅147只标的的 `Quote` 和 `Trade` 推送。异步接口用于避免同步SDK请求占用GIL阻塞行情回调，不改变数据源或增加连接。
2. 回调先注册再订阅；回调只规范化数据并写入有界内存队列，五分钟聚合、策略、风控、订单和审计在回调外顺序执行。
3. 启动时通过同一个行情连接读取60根日线和一次初始快照。日线与快照只负责初始化，不得触发开仓。
4. 账户、持仓和订单使用独立的官方 SDK 交易上下文，只允许 `lb_papertrading`。
5. `longbridge serve`、行情CLI、快照轮询、第二行情连接、项目自动重试和行情回退全部退出生产路径。官方SDK内部重连无法由Python禁用，当前不能宣称生命周期已完全受控；除明确当日模拟联调授权外保持完整日门禁。
6. 任一订阅缺失、回调溢出、行情静默、K线边界缺失或行情进程退出，立即进入 `fault_halted`，停止新开仓并保留证据。修复原因后才允许人工重新启动。

## 禁止事项

- 禁止使用行情CLI、`longbridge serve`、快照轮询、历史补录或本地模拟数据触发长桥订单。
- 禁止在行情失败后自动切换传输方式、自动重试、自动重连或使用旧值继续开仓。
- 禁止第二个行情连接、实盘、真实资金、期权、融资和未批准的策略改动。
- 禁止交易时段编辑生产源码；故障时先停止新开仓并保存证据。
- 禁止直接在 `main` 开发；每个主题必须从最新 `main` 建分支、推送远端、测试后合并。

## 完成标准

除2026-09-08当日明确授权的订单联调外，只有完整交易日验收产物通过才能恢复模拟新开仓；只有连续三个完整交易日通过才能宣布行情整改稳定。联调成功、接口连接成功与系统长期稳定是不同结论。
