# 当前执行规则

## 开始任务

1. 读取 `plans/active-plan.md`、`docs/status.md`、`docs/architecture.md`。
2. 获取最新 `origin/main`，从它创建单一主题的 `codex/*` 分支或独立工作树。
3. 修改前保存用户工作区；禁止丢弃来源不明的改动和运行产物。
4. 交易时段禁止修改生产源码。故障时停止新开仓并保留诊断证据。

## M15 行情

- 生产只能使用官方 `longbridge==4.5.0` SDK 和一个长期 `QuoteContext`。
- 回调必须在订阅前注册；同一连接按配置批次订阅147只标的的 `Quote` 和 `Trade`，完成后调用 SDK 订阅查询确认147/147。
- 同一连接在订阅前读取每个标的最近60根日线，共8820条；任一标的不足时整场停止，不允许部分运行。
- 订阅完成后只读取一次147只初始快照；快照只初始化价格状态，不能触发开仓。
- 回调只校验时间戳、规范化数据和入有界队列。K线聚合、策略、账户、订单、文件和看板均不得在回调内运行。
- `Trade` 推送生成真实五分钟开高低收和成交量；`Quote` 推送维护最新价格和行情健康。
- 无成交标的可生成 `official_sdk_no_trade_carry_forward` 零成交平K线，但不得触发开仓。
- 行情CLI、`longbridge serve`、快照轮询、历史补录和本地模拟数据均无开仓资格。

## 故障处理

- 不自动重试订阅，不自动重连，不切换端点，不回退快照或CLI。
- 任一订阅失败、订阅覆盖不足、回调队列溢出、参考行情静默、K线边界不完整或行情子进程退出，状态立即写为 `fault_halted`。
- `fault_halted` 时新开仓关闭；看护器只报告故障，不重启行情或父进程。
- 必须先定位并修复明确原因，再由人工使用正式配置重新启动。
- 重启不得补交故障期间旧信号，不得重放历史买入、卖出草稿或本地账本事件。

## 账户与订单

- 只允许 `lb_papertrading`；禁止实盘、真实资金、期权和融资。
- 账户、持仓、订单和成交使用独立官方 SDK 上下文，账户快照正常周期为15秒。
- 账户快照超过45秒、账户类型不明、持仓或订单读取失败时停止新开仓。
- 新开仓必须同时通过部署清单、配置和源码指纹、完整实时行情边界、日线缓存、账户快照、策略合同和既有风控。
- 未取得长桥订单号只能记为待确认，不得重发；成绩只统计长桥实际成交。
- 本地模拟数据不得进入长桥信号、订单、持仓、退出或盈亏计算。

## 清仓

- 清仓脚本只在用户明确授权的纽约交易日和美股常规交易时段运行。
- 清仓前单次确认模拟账户、持仓、挂单和官方 SDK 当前行情；任一数据缺失立即停止。
- 清仓只提交一次市价退出请求。市价单失败后不得自动改挂限价单，不得按成本价代替实时行情，不得重复提交。
- 只有持仓、挂单和待确认订单均为0，才能激活新的测试编号。

## 部署

- 自动启动只使用：
  - `config/m15_longbridge_marketdata.production.json`
  - `config/m15_opening_trade_readiness.production.json`
  - `config/m15_background_watchdog.production.json`
- 新开仓前必须在干净、已推送远端的提交上签发部署清单。
- 运行提交、配置哈希、源码哈希或部署清单不一致时只允许退出。
- 每个主题执行编译、聚焦单测、敏感信息扫描、大文件检查和 `git diff --check` 后才可合并。

## 验收

- 下一完整交易日只读要求：147/147订阅、8820条日线、78/78边界、11466/11466实时K线、零盘后补录、零行情重启、账户快照小于45秒、信号处理95分位小于1秒。
- 一个完整交易时段通过后，下一交易日恢复模拟新开仓；连续三个完整交易时段通过后才宣布稳定。
- 300只扩展必须在稳定后从独立分支只读验收，不得直接替换147只生产池。

历史执行规则只存放于 `docs/archive/` 与 `docs/decisions/`，不得作为当前生产依据。
