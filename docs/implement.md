## 清仓

- 清仓脚本只在用户明确授权的纽约交易日和美股常规交易时段运行。
- 清仓前单次确认模拟账户、持仓、挂单和官方 SDK 当前行情；任一数据缺失立即停止。
- 清仓只提交一次市价退出请求。市价单失败后不得自动改挂限价单，不得按成本价代替实时行情，不得重复提交。
- 只有持仓、挂单和待确认订单均为0，才能激活新的测试编号。

## 部署

- 自动启动只使用：
  - `config/m15_longbridge_marketdata.production.json`
  - `config/m15_opening_trade_readiness.production.json`
  - `config/m15_background_watchdog.production.json`
- 自动启动只拉起M15 SDK和M15看护器，不启动本地盘后研究调度器。
- 新开仓前必须在干净、已推送远端的提交上签发部署清单。
- 正式启动还须验证运行解释器和SDK原包来源；运行提交、依赖来源、配置哈希、源码哈希或部署清单不一致时不得取得新开仓资格。旧正常态仅可显示为故障前快照，不可据此给当前状态签发通过。
- 每个主题执行编译、聚焦单测、敏感信息扫描、大文件检查和 `git diff --check` 后才可合并。

## 验收

- 下一完整交易日只读要求：147/147订阅、8820条日线、78/78边界、11466/11466分类明确的实时K线、零盘后补录、无未处理的数据中断或缺口、账户快照小于45秒、信号处理95分位小于1秒。
- 一个完整交易时段通过仅提供恢复资格依据，不自动武装订单；连续三个完整交易时段通过才宣布稳定。SDK内部事件不可观测不得记录为零次。无成交延续K线不可开仓，没有合格信号允许零订单。
- 本轮不执行300只扩展；后续需稳定后另立计划和独立分支，只读验收，不得直接替换147只生产池。
