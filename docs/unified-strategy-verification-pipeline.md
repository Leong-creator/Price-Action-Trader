# 统一策略验证系统

本项目后续对用户展示时，统一使用“统一策略验证系统”这个口径，不再把 `M12`、`M13`、`M14`、`M15` 当作用户需要理解的业务名词。

内部编号仍可保留，因为大量脚本、报告和回归测试已经依赖这些路径。保留编号是为了降低回归风险，不代表系统要继续割裂汇报。

## 中文模块名

| 用户看到的模块 | 内部编号 | 做什么 |
| --- | --- | --- |
| 行情和信号模块 | `M12` | 拉取只读行情，生成当天信号、本地模拟账户状态和开平仓记录 |
| 本地模拟账本模块 | `M13` | 把本地模拟账户操作整理成每日策略账本和成绩单 |
| 策略分层和风控模块 | `M14` | 按运行单元判断推进、降仓推进、立即修复或辅助模块身份 |
| 长桥模拟账户预演模块 | `M15` | 把本地模拟订单转成长桥模拟账户格式的订单草稿，只做本地记录和稳定性对比 |

## 当前边界

- 长桥模拟账户第一阶段只做订单草稿和本地账本，不连接账户、不读取凭证、不提交订单。
- 所有非修复主策略运行单元都可以进入模拟账户测试名单；修复策略继续保留本地模拟和本地订单草稿，但不进入正常提交链路。
- 长桥模拟账户预演按 `6000 USD` 共享资金池计算仓位，默认总敞口不超过 `3600 USD`，单标的不超过 `600 USD`，并按策略档位限制单笔风险和单策略敞口。
- 第一阶段不做碎股、不做融券做空、不做期权；看空开仓只记录为草稿，不提交。
- 订单类型允许普通限价单和突破触发限价单；无对应模拟账户持仓的平仓只保留本地草稿。
- 旧版历史净利润是错误产物，不显示、不入账、不参与任何策略判断。
- 本地模拟和长桥模拟账户预演要逐笔对比：标的、方向、数量、限价、开仓/平仓动作、风控阻断原因。
- 只有在用户单独批准纸面账户令牌和首次模拟订单后，才允许进入真实长桥模拟账户下单阶段。
