# 统一策略验证系统

本项目后续对用户展示时，统一使用“统一策略验证系统”这个口径，不再把 `M12`、`M13`、`M14`、`M15` 当作用户需要理解的业务名词。

内部编号仍可保留，因为大量脚本、报告和回归测试已经依赖这些路径。保留编号是为了降低回归风险，不代表系统要继续割裂汇报。

## 中文模块名

| 用户看到的模块 | 内部编号 | 做什么 |
| --- | --- | --- |
| 行情和信号模块 | `M12` | 拉取只读行情，生成当天信号、本地模拟账户状态和开平仓记录 |
| 本地模拟账本模块 | `M13` | 把本地模拟账户操作整理成每日策略账本和成绩单 |
| 策略分层和风控模块 | `M14` | 按运行单元判断推进、降仓推进、立即修复或辅助模块身份 |
| 长桥模拟账户实时验证模块 | `M15` | 实时会话守护器在常规交易时段按顺序串联行情事件采集器、实时信号路由器和实时执行链路；实时执行链路走独立风控后进入长桥模拟账户；本地预演只保留为复盘审计 |

## 当前边界

- 长桥模拟账户与本地模拟彻底隔离：长桥实时链路不读取本地模拟开仓、平仓、账本，也不用 M13/M14 完整重算决定每笔下单。
- 长桥模拟账户实时信号来源是 `m15_realtime_market_events.jsonl` 这类实时行情/新 K 线事件；第一版由只读长桥 K 线采集器生成，后续可以替换为 SDK 行情订阅，但旧快速队列和本地模拟账本不得作为信号来源。
- 长桥实时会话守护器只负责交易窗口内串联实时行情、实时信号和实时执行；它不触发 M12.37 once-mode，不读取本地模拟账本，也不把旧快速队列当成下单来源。
- 实时信号路由器现在包含通用实时价格行为检测器，白名单内的日线和 5 分钟运行单元按各自周期独立生成信号；修复策略、辅助模块和影子变体仍只留在本地模拟，不占长桥实时执行资源。
- 所有非修复、非辅助、非影子救援的正式运行单元可以进入长桥实时测试名单；修复策略继续保留本地模拟，不产生长桥实时信号。
- 长桥模拟账户按 `10000 USD` 共享资金池计算仓位，默认总敞口不超过 `6000 USD`，单标的不超过 `1500 USD`，并按策略档位限制单笔风险和单策略敞口。
- 第一阶段不做碎股、不做融券做空、不做期权；看空开仓只记录为草稿，不提交。
- 订单类型允许普通限价单和突破触发限价单；长桥持仓的平仓只由长桥账户自身持仓和实时价格触发，不接受本地模拟平仓指令。
- 旧版历史利润字段是错误产物，不显示、不入账、不参与任何策略判断。
- 旧快速队列和全策略订单预演只做本地复盘、稳定性审计和历史兼容，不再作为长桥下单来源。
- 只有用户单独批准纸面账户令牌和模拟账户提交开关后，才允许向长桥模拟账户发起订单；真实资金和实盘账户仍禁用。
