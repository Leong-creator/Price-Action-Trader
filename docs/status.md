# 项目状态

## 当前结论

- 代码基线：`main` 已包含工作区治理、行情对照、官方 SDK 单长连接、五分钟K线完整性、恢复状态机和行情可观测性。
- 账户边界：只允许 `lb_papertrading`；实盘、真实资金、期权和融资未启用。
- 行情传输：生产只允许一个长期 `longbridge serve` JSON-RPC行情连接。固定147只策略池与池外已有持仓监控标的按每批10只订阅 `quote + trades`；账户、持仓和订单继续使用官方SDK。
- K线：逐笔成交生成五分钟开高低收和成交量；无成交标的生成 `no_trade_carry_forward` 零成交平K线且禁止开仓。
- 订单资格：初始快照、诊断快照、历史K线和盘后补录均不能触发新开仓。
- 当前门禁：生产配置明确要求 `1` 个完整交易时段；旧“两日只读门禁”名称已经退出写入路径。当前尚未取得该完整交易时段证据，因此模拟账户新开仓保持关闭。
