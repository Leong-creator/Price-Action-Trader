# 项目状态

## 当前结论

- 官方 SDK 行情整改和看护阶段判断修复均已合并并推送到 `main`。
- 账户边界：只允许 `lb_papertrading`；实盘、真实资金、期权和融资未启用。
- 行情传输：生产只允许官方 `longbridge==4.5.0` SDK 的一个长期 `QuoteContext`，不再使用 `longbridge serve` 或行情CLI。
- 数据流：官方 SDK 报价和逐笔成交推送进入有界内存队列，随后顺序聚合五分钟K线并触发冻结策略合同。
- 行情故障处理：立即 `fault_halted` 并停止新开仓，不自动重试、重连或回退其他行情源。
- 本地研究系统与长桥行情、信号、订单、持仓和盈亏完全隔离。
