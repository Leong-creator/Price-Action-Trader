# 项目状态

## 当前结论

- 代码基线：`main` 已包含工作区治理、行情对照、官方 SDK 单长连接、五分钟K线完整性、恢复状态机和行情可观测性。
- 账户边界：只允许 `lb_papertrading`；实盘、真实资金、期权和融资未启用。
- 行情传输：生产只允许 `official_sdk_persistent_websocket`。147只标的按每批10只订阅 `Quote + Trade`。
- K线：逐笔成交生成五分钟开高低收和成交量；无成交标的生成 `no_trade_carry_forward` 零成交平K线且禁止开仓。
- 订单资格：初始快照、诊断快照、历史K线和盘后补录均不能触发新开仓。
- 当前门禁：新的完整交易日行情门禁尚未取得证据，因此模拟账户新开仓保持关闭。

## 已验证证据

- 开盘验收已绑定当前 `paper_contract_v1` 执行配置，并按一个完整交易日行情门禁展示等待状态。
- 后台看护已识别“非交易时段且完整交易日门禁尚未通过”为正常等待状态；只要SDK、账户和部署均健康，就不会把新开仓按计划关闭误报成系统故障。

- 生产SDK配置已与当前冻结的合同 v1 对齐：路由、执行、持仓管理和正式测试编号均使用 `20260806` 合同版本，不再引用7月旧简化配置。

- 完整交易日门禁关闭新开仓时，已有持仓的止损、目标和合同退出继续使用纸面SDK交易连接；开仓候选只记审计，不会传给订单客户端。

- 官方 `longbridge==4.5.0` 非交易时段订阅冒烟：3只报价3/3；147只按每批10只时，报价、逐笔成交和两者同时订阅均为147/147。
- 每批50只会触发官方 SDK 请求超时，因此生产固定每批10只。
- 隔离安装的 `longbridge serve 0.28.2` 已校验安装包，但现有 CLI OAuth 缓存刷新返回 `invalid_request`；它是未完成对照，不是生产回退路径。
- 五分钟边界、恢复与部署门禁、看板和开盘验收聚焦测试均已通过；详细提交与决策见 `docs/decisions/2026-08-22-*.md`。
