# M15 单次行情订阅决策

- 长桥官方订阅接口单次最多500只标的，每个用户同时最多500只。
- 本机只读实测中，147只按每批20只订阅时，第8次请求超时，只得到140只；缺失7只单独订阅全部成功。
- 同一环境一次订阅147只和一次订阅156只都在1秒内完整成功。
- 生产固定使用一个官方SDK长连接、一个不超过500只的订阅请求。账户、看板和本地研究不得创建第二个行情连接。
- 若单次请求失败，生产连接只重试整批，并以服务端实际订阅集合判定缺失标的；不得把客户端超时直接等价成整批失败。实际覆盖不完整时停止新开仓并进入现有冷却恢复，不得逐标的扇出、回退快照轮询或重新制造高频多请求风暴。逐标的定位只允许独立诊断程序执行。
