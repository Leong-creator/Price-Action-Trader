# M15 开盘重连订阅节流与回执兼容

## 决策

- `longbridge serve` 行情按官方单请求最多500只的契约提交；147只主池一次订阅，池外持仓监控另一次订阅。
- 同一组标的先订阅 `quote`，再订阅 `trades`；不再把两个高流量字段合并到同一个启动请求。
- 相邻订阅请求间隔由0.5秒提高到1.25秒，避免一次 `quote + trades` 订阅产生的上游请求撞到行情接口短周期限频。
- `quote.subscriptions` 恢复查询同时接受当前CLI返回的 `sub_types: ["quote", "trades"]`、订阅响应的 `fields` 和旧兼容结构 `sub_type: [1, 4]`。
- 行情子进程显式固定官方 `.cn` HTTP与WebSocket地址，绕过返回空连接命令的自动端点发现；只向子进程增加长桥官方环境变量，原有代理变量原样保留。
- 行情连接、账户连接和策略合同不变；快照没有开仓资格，完整交易日门禁继续关闭新开仓。

## 证据

- 纽约交易日2026-08-27开盘后，旧配置先收到SPY/QQQ推送，随后连接静默；自动重连只完成90/156进度并因剩余订阅超时失败。
- 长桥日志显示0.5秒间隔下连续出现 `429002`，响应要求稍后重试。
- 实际 `quote.subscriptions` 响应使用 `sub_types` 字段；旧解析器未识别该字段，因此无法利用已经建立的服务器订阅恢复本地状态。
- 显式固定官方行情端点后，147只单请求实测返回147/147，并同时收到报价和逐笔成交；旧的小批次结论来自端点发现异常期间，不再作为生产依据。
- 盘中同连接对照显示：147只合并字段请求可触发30秒请求超时；拆为报价和逐笔成交两个请求后分别用时0.187秒和0.128秒，最终订阅查询为147/147，随后5秒收到383条报价和237条逐笔成交。
- 自动端点发现路径下，长桥行情命令返回空连接信息并最终 `connect timeout`；同一网络显式指定 `https://openapi.longbridge.cn` 和 `wss://openapi-quote.longbridge.cn/v2` 后，SPY只读行情在1秒内返回。

## 回退

如新节流仍无法完成147只订阅，保持完整交易日门禁和停止新开仓，回退本提交；不得回退到快照轮询取得开仓资格，也不得改变策略或仓位绕过行情故障。
