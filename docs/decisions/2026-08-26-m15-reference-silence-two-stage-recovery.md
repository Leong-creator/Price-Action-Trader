# M15参考行情静默两级恢复

## 决定

生产长期行情连接遇到SPY和QQQ同时静默时，不再在30秒阈值立即重启。

- 30秒：停止新开仓，保留已有持仓退出和账户维护。
- 静默后出现新的结构不完整五分钟边界：重启行情连接。边界完整但参考行情仍过期时继续只允许退出，不提前重连。
- 没有边界证据但静默持续超过305秒：重启行情连接。
- 行情子进程心跳过期：沿用5秒心跳门禁立即重启。
- 重连次数只在当前连接至少形成一根完整五分钟K线后清零。

## 原因

北京时间2026-08-26（纽约交易日2026-08-25）的生产证据显示，行情子进程仍每秒上报心跳、读取错误为0、队列积压为0，但SPY和QQQ出现约30秒推送间隔时，父进程立即终止了完整订阅连接。重复重连又会触发147只全量重订阅，增加上游等待和熔断概率。

短时参考标的无推送足以停止新开仓，但不足以证明整个长期连接已经死亡。五分钟边界完整性和子进程心跳是更直接的连接证据。

## 不变边界

- 只使用长桥模拟账户。
- 不修改策略、仓位、止损、目标或订单类型。
- 不允许快照、历史补录或本地模拟取得新开仓资格。
- 不增加第二个行情连接。
