1. 时间模块：固定预算对照微软工具与原采样器，保存实际服务器IP、原始样本及Windows/WSL时差证明。保留原0.5秒门槛与失败历史；依据结果修复具体问题，不重复采样直到碰到通过。

3. 接回与监控：唯一启动入口改接Windows收流、WSL原聚合/router；日常监控不再刷新旧账户/旧行情产物，来源清单覆盖新程序。官方Windows环境使用稳定路径，来源来自已核官方发布文件。
4. 实时证据：每根分类K线、排除原因、原始时刻、边界处理及策略耗时落盘；另建完整日验收，保留诊断/行情资格/账户交易资格的区别。
5. 验证：离线反例、真实无SDK生命周期检查、独立审查后部署；盘中可验证持续输入。使用最终日常入口覆盖完整日，正常日147×78=11,466条分类记录，一日提供行情恢复资格，连续三个正常交易日通过才称稳定。

主代理负责计划、配置、旧入口退役、监控与部署集成；独立实现分支分别负责看护、时间、消费证据，独审后集成。高风险启动和认证生命周期改动需独立复核并标记人工复核；本次已授权只读行情部署无需重复索取许可。正式账户与订单恢复仍属后续单独阶段。

## 验证边界

- 长桥官方SDK、147只股票、原K线生成方式及策略/风险参数保持；不增加回退来源、重试或旧信号补交。
- 完整日必须由实时记录计算；半日市单独识别，本轮不得以78条正常日模板伪造。
- 一个策略完成判断不保证出现信号，背景不足如实记载；无成交延续K线不可作为开仓输入。
- 时间检查不代表行情网络延迟，Windows时间证明不自动代表WSL时间证明。
- 运行失败后留证停止；退出不明保留阻断及认证，不清文件制造恢复。
- 三日实测是未来实际时段的结果，不以任务登记或离线回放宣称完成。
