# 官方接入点与当前发布版验证结果

日期：2026-09-19。结论：**本机采用已核验的官方方法仍未解决行情接入，停止本阶段长桥实连，转入替代源资格确认。** 不向外反馈，不把失败样例说成恢复，不把行情故障转嫁给策略。

## 验证为什么符合官方方法

官方[快速开始](https://open.longbridge.com/docs/getting-started#api-host)明确允许通过 `LONGBRIDGE_REGION=cn/hk` 选择网络接入点；hk不是更改账户数据中心。SDK自行选择官方地址，没有手写URL、DNS注入或修改系统代理。官方[订阅接口](https://open.longbridge.com/docs/quote/subscribe/subscribe)允许500只，现有147只一次提交，不添加经验分批。

此前4.5.0独立样例有成功也有失败，已证明仅删除旧封装/改同步/单次全量不足以宣称修复。官方[5.0.0发布](https://github.com/longbridge/openapi/releases/tag/v5.0.0)及[PyPI文件](https://pypi.org/pypi/longbridge/5.0.0/json)可核验；虽未发现针对本故障的关键源码修复，构建与全部依赖尚未证明相同，因此最后追加一次当前官方二进制对照，没有正式升级。

两个新实验均使用此前样例原字节，SHA256 `22b624aafead9302158d16dcfa5cb31cde32b081a44de9b5a7eb9639382243e5`；样例采用官方公开调用方式，加入既有安全认证文件读取、147只输入及Trade公开回调，不是未经改动的下载文件。零项目scripts导入、零账户/订单调用，单147只Quote+Trade，环境代理保持。外部控制器只做单连接排他、日志观察和60秒期限，不改SDK请求语义、不重试；各8项离线测试及独立复核通过后各执行一次。
