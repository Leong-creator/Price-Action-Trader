# M15 门禁按一个完整交易时段定义

## 决定

M15 的生产行情门禁固定为一个完整美股常规交易时段，而不是按名称或日历等待两个交易日。正式配置使用：

- `complete_session_gate_enabled=true`
- `required_complete_sessions=1`
- 通过状态 `complete_session_gate_passed`
- 阻断原因 `complete_market_session_gate`

完整时段必须同时满足147只订阅、8820条日线、78个五分钟边界、11466根实时K线、零盘后补录、零行情重启、账户快照及时和既定延迟标准。

## 原因

旧字段 `two_day_readonly_gate` 的名字与实际执行不一致，容易让运行状态、看板和人工判断误认为必须额外空等两个交易日。系统真正需要的是一份完整、连续、可用于订单的实时行情证据，而不是日历天数本身。

## 兼容边界

- 旧门禁文件中的 `completed_sessions` 继续只读迁移，避免丢失已经验证的完整时段证据。
- 旧配置和旧状态字段只允许兼容读取；新配置、新状态和新看板不得写出旧名称。
- 60分钟长连接验收只能证明传输持续性，不能替代完整常规交易时段门禁。
- 门禁未通过时新开仓关闭，账户事实读取和拥有实时行情证据的已有持仓退出继续运行。

## 扩展池

300只扩展池使用同一“一个完整交易时段”定义，但它拥有独立门禁文件；147只生产门禁不能直接替代300只扩展验收。
