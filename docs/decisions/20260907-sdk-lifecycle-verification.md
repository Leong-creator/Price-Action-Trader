# 官方SDK生命周期核对

2026-09-07，固定版本 `longbridge==4.5.0`，未修改官方包、代理或策略配置。

## 已验证的事实

- Python同步及异步QuoteContext只有行情回调，无可靠的断线/重连回调，也无关闭内部重连开关。
- 官方Rust行情核心断线后等待2秒自动重新连接并恢复订阅。这发生在同一个QuoteContext内部，订阅列表完整或进程代次为1都不能证明未重连。
- 可选文件日志能够留证，但有异步调度和写入失败风险，不能作为同步禁止重连的保证。本轮没有为掩盖此限制添加日志推断或定制SDK补丁。
- 生产恢复为只读，不请求订单派发。离线回放验证代码，不签发真实交易日验收；内部重连限制需要明确解决后再宣称严格生命周期验收完成。

## 官方依据

- [4.5.0行情核心](https://github.com/longbridge/openapi/blob/v4.5.0/rust/src/quote/core.rs)：固定重连延迟及重订阅循环。
- [4.5.0美股成交条件](https://github.com/longbridge/openapi/blob/v4.5.0/rust/src/quote/store.rs)：价格与成交量各自的更新条件。本轮按此修复聚合，不能将所有逐笔成交都用来修改高低价。
- [4.5.0配置和日志](https://github.com/longbridge/openapi/blob/v4.5.0/rust/src/config.rs)：日志可失败降级，不是可靠生命周期接口。

## 尚未完成

- 官方推送能否覆盖下一完整交易日，必须由实时证据证明。
- 严格禁止官方SDK内部重连的可支持实现目前不存在于已安装Python接口；不回退CLI，不用轮询继续交易，不把未知状态当作健康。
