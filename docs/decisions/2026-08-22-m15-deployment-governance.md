# M15 部署治理决定

- 开发不得直接发生在 `main`；每个主题从最新 `main` 建立独立分支并先推送远端检查点。
- M15 新开仓前必须具备本地部署清单。清单固定提交号、运行配置和关键源码哈希。
- 清单只在部署时确认提交已存在于远端；交易进程运行时只做本地校验，不依赖 GitHub 网络。
- 工作区存在未提交源码、配置或未跟踪文件，或清单与当前提交、配置、源码不一致时，只关闭新开仓；已有持仓退出路径保持可用。
- 自动报告、账户快照、运行日志和行情历史不进入源码提交。
- 当前远端 OAuth 不具备修改 GitHub workflow 的权限，持续集成入口固定为 `scripts/run_repository_governance_ci.sh`；远端权限补齐前不得用缺失 workflow 冒充已启用云端 CI。
